## ダブルクリックで起動するデスクトップ試用版

Node.jsのインストール、ターミナル操作、操作画面へのパスワード入力は不要です。サーバーと操作画面を同梱しています。受信PCはブラウザだけで使えます。

### お使いのPCに合わせて1つダウンロード

| PC                                    | ダウンロードするファイル              |
| ------------------------------------- | ------------------------------------- |
| Apple Silicon Mac（M1 / M2 / M3以降） | `ImagePlayoutLAN-1.1.0-mac-arm64.dmg` |
| Intel Mac                             | `ImagePlayoutLAN-1.1.0-mac-x64.dmg`   |
| Windows 10 / 11・64bit Intel / AMD    | `ImagePlayoutLAN-1.1.0-win-x64.exe`   |

- Mac：DMGを開き、アプリをApplicationsへドラッグして起動。
- Windows：EXEを保存してダブルクリック。インストール操作は不要。
- 操作画面の「送出 → 受信PCの接続先…」でOUT用URLを確認・コピーできます。
- 元のソース版を起動中の場合は、先に終了してください。同じ8080番ポートを使います。

### 注意事項

Appleの署名・公証、Windowsのコード署名は未設定です。初回はOSの警告が出る場合があります。信頼する入手元であることを確認し、OSや組織のルールに従って許可してください。LAN接続を求められたら、信頼するプライベートネットワークで許可してください。

登録した画像や設定はアプリ本体とは別のユーザーデータ領域に保存します。開発者の画像・パスワードは同梱していません。既存ソース版のデータ移行は[配布版の使い方](https://github.com/atstti/ImagePlayout/blob/main/docs/%E9%85%8D%E5%B8%83%E7%89%88%E3%81%AE%E4%BD%BF%E3%81%84%E6%96%B9.md)を参照してください。

LAN専用です。ルーターのポート開放でインターネットへ直接公開しないでください。

### 検証

- Node.js / Chromiumの統合・ブラウザ・デスクトップ補助テスト：8件成功。
- GitHub ActionsのmacOS Apple Silicon / Intel、Windows環境でビルドし、生成した実アプリの自動認証、日本語画像登録、画像デコード、CUT、受信URL、データ保存先分離を確認。
- 実際の複数PC間LAN通信やOSのダウンロード警告は、利用環境での確認が必要です。
