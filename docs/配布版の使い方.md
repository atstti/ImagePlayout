# Image Playout LAN 配布版の使い方

Node.jsのインストール、ターミナル操作、管理パスワード入力なしで起動できるデスクトップ版です。サーバーと操作画面を1つのアプリにまとめています。受信PCはブラウザだけで利用できます。

## ダウンロードするファイル

| PC                                     | ファイル名に含まれる文字 |
| -------------------------------------- | ------------------------ |
| Mac（M1 / M2 / M3以降のApple Silicon） | `mac-arm64.dmg`          |
| Mac（Intel）                           | `mac-x64.dmg`            |
| Windows 10 / 11（64bit Intel / AMD）   | `win-x64.exe`            |

Macの種類はAppleメニュー →「このMacについて」で確認します。Windows ARM版は今回の配布対象外です。

**利用者向けダウンロード：[デスクトップ試用版 v1.1.0](https://github.com/atstti/ImagePlayout/releases/tag/v1.1.0)**。下の「Assets」から、自分のPCに合うDMGまたはEXEを選んでください。

開発者がGitHub Actionsの「Desktop packages」でビルドすると、成功した実行のArtifactsに3種類のファイルができます。ArtifactsはGitHubへログインしてダウンロードし、外側のZIPを展開してください。ファイルを受け取った利用者はGitHubのアカウント不要です。Artifactsの保持期間は30日です。継続的な配布には上記GitHub Releasesのダウンロードページを使ってください。

## Mac

1. DMGを開き、「Image Playout LAN」を「Applications」へドラッグします。
2. Applicationsから「Image Playout LAN」を開きます。
3. 操作画面が自動で開きます。

この配布版はAppleの署名・公証をしていません。初回はmacOSの警告で起動が止まる場合があります。入手元がこのリポジトリまたは信頼する配布者であることを確認し、システム設定 → プライバシーとセキュリティで、そのアプリの「このまま開く」が表示されていれば個別に許可してください。OS全体のセキュリティ設定を無効にする必要はありません。組織の制限がある場合は管理者へ確認してください。

LANへのアクセス許可を求められたら許可します。拒否すると受信PCと通信できない場合があります。

## Windows

1. EXEを自分のPCのフォルダーへ保存します。
2. EXEをダブルクリックします。インストーラー操作は不要です。
3. 操作画面が自動で開きます。

この配布版はコード署名をしていないため、SmartScreen等で確認が出る場合があります。信頼する入手元であることを確認し、組織のポリシーに従ってください。ファイアウォールの確認では、信頼できる**プライベートネットワーク**で通信を許可します。

## OUT画面を見る

1. メニューの「送出 → 受信PCの接続先…」を開きます。
2. 表示されたURLを、同じLANに接続した受信PCのブラウザに入力します。
3. 画像を登録・選択し、CUTまたはTAKEを押すとOUTに表示されます。
4. OUT画面をダブルクリック、またはFキーで全画面にします。

同じPCで確認する場合は「送出 → このPCでOUTを開く」も使えます。受信PCにはアプリのインストールも管理パスワードも不要です。操作PCのアプリは起動したままにしてください。アプリ終了後、受信PCは最後の画像を保持して再接続を待ちます。

## 保存と更新

登録画像・設定・パスワードはアプリ本体の外に保存されます。「送出 → 画像・パスワードの保存先を開く」で確認できます。

- Mac：`~/Library/Application Support/Image Playout LAN/data`
- Windows：`%APPDATA%\Image Playout LAN\data`

同じOSユーザーでアプリ本体を更新してもデータは残ります。バックアップはアプリ終了後に `data` フォルダーごとコピーしてください。配布ファイルには開発者の画像やパスワードを含めません。

ソース版から画像を引き継ぐ場合は、ソース版とデスクトップ版の両方を終了してから、ソース版の `data` の中身をデスクトップ版の保存先へコピーしてください。コピーすると保存先のデータは置き換わるので、先にバックアップしてください。デスクトップ版を一度起動して終了すると保存先が作られます。

別のブラウザで操作画面を開く場合はユーザー名 `admin`、保存先の `admin-password.txt` のパスワードで認証します。デスクトップ版の画面だけが自動認証します。

## 起動できないとき

- 「8080番ポートが使用中」：先に起動した `npm start` や別のサーバーを終了してから開きます。
- 受信PCにつながらない：同じLAN、IPアドレス、OSのファイアウォールを確認します。VPN等が有効な場合は、接続先一覧から実際のLANのアドレスを使ってください。
- 二重に開いた：同じデスクトップ版は既存の操作画面を手前に出します。

現在はLAN向けです。ルーターのポート開放でインターネットへ直接公開しないでください。
